# 图纸变更管理平台

面向施工项目与制造企业的图纸变更管理 Web 平台，解决“设计已改、现场仍用旧图”的问题。

## 快速开始

```bash
node src/server.js        # 或 npm start
# 打开 http://localhost:3000
```

无需任何第三方依赖（Node ≥ 22，使用内置 `node:sqlite`）。首次启动自动建库并写入演示数据。

## 核心功能

- **图纸台账**：项目下维护专业、区域、图纸编号与当前有效版本。
- **版本变更**：上传新版本必须选择变更原因并关联被替代版本；生效时自动生成版本差异记录，旧版本自动作废。
- **逐级审核**：设计 → 技术 → 项目负责人三级审核；任一级退回（须填意见）后版本回到“已退回”，必须修改并重新提交。
- **班组确认**：新版本生效后，曾领取旧图的班组自动进入待确认状态，须逐一确认收到新版本；确认即视为持有新版本，下次变更继续追踪。
- **任务管控**：施工任务关联具体图纸版本；任务仍关联已作废旧图时，系统明显提示并禁止标记完工，须先改用当前有效版本。
- **现场问题**：在图纸具体位置（点击定位）创建问题记录，支持照片、责任人、处理意见；问题永久绑定创建时的版本，图纸再次变更后仍可追溯。
- **完整演变**：图纸详情页以时间线展示从初版到当前版本的全部演变——每版审核人、审核意见、生效时间、差异记录与各班组确认状态。

## 目录结构

```
src/db.js       SQLite 建表与演示数据
src/server.js   HTTP 服务、认证与全部业务 API
public/         单页前端（原生 JS，hash 路由）
data/           SQLite 数据库与上传文件（运行时生成）
```
